# Operational Discipline

This repository treats public-repo issues as operational incidents, not passive backlog items.

## Issues Are Blocking

Every public-repo issue is a fleet-wide full stop until it is adjudicated and closed. The operator may choose the fix, defer the issue with an explicit documented decision, or close it as invalid, but the issue is not treated as ordinary backlog grooming while it remains open.

Closed-issue velocity in this repository should be read as incident response under a blocking discipline. A burst of closed issues means the fleet stopped normal forward motion to root-cause, patch, verify, and close reported gaps before continuing.

This practice is intentionally conservative for a repo that claims local orchestration, stop discipline, evidence-gated completion, and reviewable audit posture. It is not a claim that every issue is equally severe; it is a claim that public uncertainty gets resolved before the fleet resumes treating the system as clean.
